# Space Weather Monitor — homepage starter

A responsive static homepage concept for the space weather display project. It uses plain HTML, CSS and JavaScript, so it can be hosted on GitHub Pages or Cloudflare Pages without a build step.

## Preview locally

Open `index.html` in a browser. An internet connection is only needed to load the optional Google Fonts; the page layout and graphics are local CSS/HTML.

## Publish with Cloudflare Pages

1. Create a GitHub repository and upload these four files (`index.html`, `styles.css`, `script.js`, `README.md`).
2. In Cloudflare, open **Workers & Pages** and create a Pages project connected to that repository.
3. Choose **None** as the framework preset, leave the build command empty, and set the build output directory to `/` (or the repository root, depending on the setup UI).
4. Deploy. Cloudflare will provide a temporary `*.pages.dev` URL before you buy a domain.

## Before launch

- The project name is provisional; update the title and wordmark when a final name is chosen.
- The device drawing and readings are illustrative, not a photograph or live data feed. Dashes are used rather than fabricated readings.
- Add a real contact address or waitlist destination before promoting the site publicly.
- Review the feature list and wording to ensure they match the hardware and data sources you intend to support.
